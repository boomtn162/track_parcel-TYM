# ระบบติดตามพัสดุ สถานีรถไฟตันหยงมัส

เว็บแอปให้ลูกค้าตรวจได้เองว่าพัสดุที่ฝากส่งทางรถไฟจากสถานีตันหยงมัส (4419) **ถึงไหนแล้ว** และ **ถึงปลายทางหรือยัง**
โดยค้นจากเลขที่ใบส่งของ (`PAN6911-4419-00057` หรือแค่ 5 หลักท้าย `00057`) หรือจากเบอร์โทรผู้ส่ง/ผู้รับ (10 หลัก)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าลูกค้า (`/`) และหน้าเจ้าหน้าที่ (`/#staff`) อยู่ในไฟล์เดียว |
| `parser.js` | อ่านไฟล์ PDF จากระบบรถไฟ: ใบส่งของ/ใบเสร็จรับเงิน และใบนำมอบสินค้าห่อวัตถุ (รวม) |
| `Code.gs` | Backend บน Google Apps Script เก็บข้อมูลใน Google Sheets |

## สถานะพัสดุ

```
📦 รับฝากแล้ว  →  🚆 อยู่ระหว่างขนส่ง (ขึ้นขบวน xxx)  →  📍 ถึงสถานีปลายทาง  →  ✅ รับพัสดุแล้ว
                                (⚠️ มีปัญหา โปรดติดต่อสถานี: ใช้ได้ทุกขั้น)
```

## งานประจำวันของเจ้าหน้าที่

1. **ตอนรับฝาก**: บันทึก PDF ใบส่งของ/ใบเสร็จจากระบบรถไฟ แล้วเข้า `#staff` > **นำเข้า PDF** > เลือกไฟล์ (เลือกหลายไฟล์พร้อมกันได้)
   พัสดุจะเข้าระบบด้วยสถานะ “รับฝากแล้ว” พร้อมชื่อ เบอร์ ปลายทาง และขบวน
2. **ตอนส่งขึ้นขบวน**: นำเข้า PDF **ใบนำมอบสินค้าห่อวัตถุ (รวม)** ของขบวนนั้น ทุกเลขที่ในใบจะเปลี่ยนเป็น “ขึ้นขบวนรถแล้ว” ให้อัตโนมัติ
   (เลขที่ที่ยังไม่มีในระบบจะถูกสร้างให้ด้วย ข้อมูลผู้ส่ง/ผู้รับเติมทีหลังได้โดยนำเข้าใบส่งของ)
3. **เมื่อพัสดุถึงปลายทาง/ผู้รับมารับแล้ว** (ดูจากระบบรถไฟ หรือสถานีปลายทางแจ้งมา): ในแท็บ **รายการพัสดุ** ติ๊กเลือกรายการ แล้วกด **📍 ถึงปลายทาง** หรือ **✅ รับของแล้ว**
4. ส่ง QR ให้ลูกค้าได้: กดเลขที่พัสดุ > **พิมพ์ QR ให้ลูกค้า** ลูกค้าสแกนแล้วเห็นสถานะทันที (ลิงก์รูปแบบ `.../?q=PAN6911-4419-00057`)

## การติดตั้ง

### 1. ลองใช้ก่อน (โหมดทดลอง)
เปิด `index.html` ได้เลย ข้อมูลจะเก็บไว้ในเบราว์เซอร์เครื่องนั้นเครื่องเดียว PIN เจ้าหน้าที่คือ `4419`
มีข้อมูลตัวอย่าง (สมมติขึ้น) ให้ลองค้นหา `00001`–`00004`

### 2. ฐานข้อมูลจริง (Google Sheets ใช้ฟรี)
1. สร้าง Google Sheet ใหม่ > เมนู **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิม วางโค้ดจาก `Code.gs` ทั้งไฟล์ **เปลี่ยน `STAFF_PIN_DEFAULT`** เป็น PIN ที่ต้องการ
3. เลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้** (อนุญาตสิทธิ์) ระบบจะสร้างชีต `Parcels` ให้
4. **การทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` ไปใส่ใน `CONFIG.API_URL` ที่ส่วนบนของ `index.html`
   (หรือใส่ในหน้า เจ้าหน้าที่ > ตั้งค่า เพื่อทดสอบเฉพาะเครื่อง)
6. ใส่เบอร์โทรและเวลาทำการของสถานีใน `CONFIG.STATION_PHONE` / `CONFIG.STATION_HOURS`

> แก้ `Code.gs` ภายหลังแล้ว ต้องทำ **การทำให้ใช้งานได้ > จัดการ > แก้ไข > เวอร์ชันใหม่** ทุกครั้ง
> เปลี่ยน PIN ได้ที่ Project Settings > Script Properties > `STAFF_PIN`

### 3. เปิดให้ลูกค้าใช้ผ่าน GitHub Pages
GitHub repo > **Settings > Pages** > Source: *Deploy from a branch* > เลือก branch `main` / root
จะได้ลิงก์ประมาณ `https://boomtn162.github.io/track_parcel-TYM/` นำไปทำ QR ติดที่เคาน์เตอร์ หรือพิมพ์ลงใบส่งของ

## ข้อมูลส่วนบุคคล (PDPA)

- หน้าลูกค้าแสดงชื่อแบบปิดบัง (`ดว*** แส***`) และเบอร์แบบ `092-xxx-2369` เท่านั้น **ไม่แสดงที่อยู่** โดย server เป็นคนปิดบังก่อนส่งข้อมูลออกมา
- ค้นด้วยเบอร์โทรต้องใส่ครบ 10 หลัก
- งานของเจ้าหน้าที่ทุกอย่างต้องใช้ PIN ซึ่งตรวจที่ฝั่ง server
- **ห้าม commit ไฟล์ PDF/CSV ของลูกค้าขึ้น GitHub** (`.gitignore` กันไว้ให้แล้ว) เพราะ repo ที่เปิด GitHub Pages เป็นสาธารณะ
